# Shruti Mokhashi — Digital Resume

**Live site:** [shrutimokhashi34.github.io](https://shrutimokhashi34.github.io)

A personal resume website for my work in data engineering and data analytics. It brings together my experience, projects, skills, certifications and resume in one place, styled like a cloud console.

## What's on the site

- **Introduction** with my core stack, cloud platforms and current status
- **Experience** at ZS Associates, including ETL pipelines, KPI frameworks and data quality automation
- **Projects**, including my end-to-end banking data platform (ranked 58th of 3,500 in Google Patchamomma 2026), with links to the project showcase and code
- **Skills**, grouped by data engineering, languages, BI, libraries and practices
- **Credentials**: certifications with links to each credential, achievements, education and languages
- **Resume**: an in-page PDF preview with a download button and a "last updated" timestamp
- **Links and sharing**: contact details, a QR code, copy-link and share buttons

## Built with

- HTML, CSS and vanilla JavaScript in a single page, with no build step or framework
- [IBM Plex Mono and IBM Plex Sans](https://fonts.google.com/?query=IBM+Plex) from Google Fonts
- [PDF.js](https://mozilla.github.io/pdf.js/) to preview the resume in the page
- The GitHub REST API to show when `resume.pdf` was last updated
- [GoatCounter](https://www.goatcounter.com/) for cookie-free visitor analytics
- Hosted on [GitHub Pages](https://pages.github.com/)

The layout is responsive for phones, tablets and laptops, and it follows the device's light or dark mode.

## Repository structure

```
├── index.html   # the whole site: content, styles and scripts
├── resume.pdf   # the resume shown and downloadable on the site
├── photo.jpg    # profile photo
├── preview.jpg  # link preview image shown when the site is shared
├── robots.txt   # tells search engines they may index the site
├── sitemap.xml  # page list for Google Search Console
└── README.md
```
